# Radar de Diamantes SSTeam

App web para el minijuego de diamantes del clan SSTeam. Es un solo archivo (`index.html`), sin dependencias ni servidor.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `radar-diamantes`), público.
2. Sube `index.html`, `README.md` y `.nojekyll` (botón **Add file → Upload files**).
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. Espera uno o dos minutos. El enlace será:
   `https://TU-USUARIO.github.io/radar-diamantes/`

## Notas

- El tablero se guarda en el navegador de cada persona (localStorage); no se comparte entre usuarios.
- Usa Google Fonts; si no hay internet, cae a la fuente del sistema.
